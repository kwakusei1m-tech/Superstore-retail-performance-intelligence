# Tools stack

## Tier 1 - Portfolio and no-code evaluation
- Excel: scoring sheets, reconciliation, pivoted error analysis, agreement and trend reporting.
- Word/Markdown: task briefs, guidelines, observations, adjudication notes and model cards.
- PowerPoint: executive readouts of pass rate, error severity, drift and recommendations.
- GitHub: version control, pull-request review, issue tracking, release notes and reproducibility.

## Tier 2 - Repeatable local QA
- Python, Pandas and Jupyter: schema checks, batch analysis, agreement metrics and automated reports.
- CSV/JSON/YAML: portable task, rubric and result formats.
- File-diff, checksum and Office/PDF rendering tools: final-state validation.

## Tier 3 - Scalable evaluation
- Evaluation APIs/platforms: datasets, runs, model configurations and graders.
- Deterministic graders: exact strings, calculations, file structure and state.
- Model judges: nuanced quality dimensions, only after human calibration.
- Expert human review: ambiguous, high-risk, linguistic and business-judgment cases.

## Collaboration and governance
GitHub Issues/Projects or approved Jira/Notion equivalents; Slack/Teams for coordination; approved secure storage for source files and transcripts. Follow client tool and data-retention rules.
