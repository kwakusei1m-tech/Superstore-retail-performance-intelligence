# Task 03 - Pairwise business-report evaluation

## Prompt
Compare Report A and Report B for the same Superstore decision. Select the stronger response, score both independently and write a 150-word rationale using criterion-level evidence. If neither is acceptable, state why and provide the minimum correction set.

## Review lenses
Decision clarity, source grounding, business narrative, calculation accuracy, limitations, professional Word usability and actionability. Do not allow polished formatting to compensate for a material factual error.

## Required output
Winner/tie; independent scorecards; decisive evidence; severity-coded defects; confidence; minimum remediation.
