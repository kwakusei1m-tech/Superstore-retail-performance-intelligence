# Task 06 - Cross-format business-package agent

## Prompt
Using the validated Superstore inputs, update an Excel model, a Word report and a PowerPoint briefing as one governed package. Do not overwrite sources. All three deliverables must use the same KPI definitions, reporting period, findings and limitations.

## Checks
Files open; expected names/locations exist; workbook refreshes; Word conclusions reconcile; PowerPoint headlines reconcile; links and version metadata are present; no source is deleted; discrepancies are listed in a handoff note.

## Why this matters
This task demonstrates the practical computer-workflow focus of current AI-evaluation roles while using your strongest domain evidence: advanced Excel, professional documents, executive briefing and auditable QA.
