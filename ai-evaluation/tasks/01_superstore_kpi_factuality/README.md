# Task 01 - Superstore KPI factuality and narrative

## Prompt
Review an AI-generated executive summary against the validated Superstore workbook and report. Return a corrected 250-word summary, an error table and five evidence-linked recommendations. Preserve the distinction between transaction lines, orders and customers. Do not assert causation from descriptive correlations.

## Supporting assets
- `workbook/Superstore_Retail_Performance_Intelligence_Excel_BI_v1.0.xlsx`
- `docs/Superstore_Retail_Performance_Intelligence_Report.docx`
- `docs/Superstore_Executive_Briefing_Validated_Model.pptx`

## Gold anchors
- 9,994 valid sales lines; 5,009 orders; 793 customers.
- Sales: $2,297,200.86; profit: $286,397.02; profit margin: 12.47%.
- Every claim must identify the governing source or measure; recommendation language must distinguish evidence from proposed action.

## Seeded traps
Confuse orders with lines; calculate margin from rounded values; claim discounts “cause” losses; copy an outdated KPI from a static chart; recommend action without owner/metric.
