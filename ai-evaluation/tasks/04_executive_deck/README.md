# Task 04 - Executive briefing deck evaluation

## Prompt
Evaluate an AI-generated 6-8 slide Superstore briefing for a 10-minute executive discussion. Confirm KPI lineage to the validated model, assess prioritization and recommendation logic, and return a slide-level correction plan.

## Checks
The opening slide states the decision; KPI definitions and period are visible; every chart has a takeaway; priorities use impact/urgency/feasibility; recommendations name action, owner, timing and measure; limitations are explicit; no chart conflicts with the workbook/report.

## Critical failures
Material KPI contradiction, illegible or corrupt slides, unsupported causal claim presented as fact, or recommendation disconnected from analysis.
