# Task 05 - Language, locale and contextual quality

## Prompt
Evaluate content for grammar, clarity, factual grounding, locale conventions, tone and contextual relevance. Use a locale-specific style guide and a verified fluent reviewer. Flag ambiguity rather than guessing.

## Portfolio-safe implementation
Start with English variants (for example, UK/US spelling, date and number conventions). Add another language only when you can document your own proficiency or name a qualified reviewer who created/approved the gold answer. Machine translation is not a substitute for linguistic gold data.

## Checks
Meaning preservation, terminology, grammar, idiom, dates/currency/number formats, audience tone, culturally inappropriate assumptions and source fidelity.
