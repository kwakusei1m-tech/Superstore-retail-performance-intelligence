# AI Evaluation Portfolio Kit

This GitHub-ready package turns the validated Superstore Excel BI project into a practical AI-evaluation portfolio. It demonstrates task design, rubric construction, agent observation, factuality review, reviewer calibration, error analysis and continuous improvement.

## EVAL-OPS flow

1. **Establish** the capability, user, risk and decision.
2. **Version** the prompt, files, environment, model and rules.
3. **Author** a self-contained task, reference solution and edge cases.
4. **Lock** the rubric, graders, weights and critical-failure rules.
5. **Observe** repeated trials and preserve outputs, files and traces.
6. **Produce** evidence-linked scores, error labels and concise feedback.
7. **Standardize** through calibration, adjudication, drift review and regression tests.

## Portfolio tasks

| ID | Evaluation task | Demonstrated capability |
|---|---|---|
| 01 | Superstore KPI factuality | Grounding, calculations, evidence and claims |
| 02 | Excel workflow agent | Practical computer workflow and file-state grading |
| 03 | Business report pairwise review | Comparative judgment and professional writing |
| 04 | Executive briefing deck | KPI narrative, prioritization and decision usefulness |
| 05 | Language and locale quality | Grammar, locale and cultural nuance with fluent review |
| 06 | Cross-format package | End-to-end Excel-Word-PowerPoint consistency |

## How to integrate

Copy this folder to `ai-evaluation/` in the Superstore GitHub repository. Keep the validated workbook, report and briefing deck in their existing repository locations, then update the relative paths in each task specification. Do not commit confidential data, model transcripts or client material.

## Interview demonstration

Select one task, explain the EVAL-OPS stages, score two sample responses, identify the dominant error pattern and propose one prompt/rubric/data improvement plus a regression case.
