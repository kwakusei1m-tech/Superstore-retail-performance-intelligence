## Superstore Retail Performance Intelligence — Refreshable Excel BI

[![Superstore Retail Performance Intelligence preview](https://raw.githubusercontent.com/kwakusei1m-tech/Superstore-retail-performance-intelligence/main/assets/images/social-preview.png)](https://github.com/kwakusei1m-tech/Superstore-retail-performance-intelligence)

Rebuilt a static Superstore analysis as a governed, refreshable Microsoft Excel BI solution using parameterized Power Query ETL, a Power Pivot star schema, 63 explicit DAX measures, data-quality and refresh controls, and interactive dashboards with slicers and timelines.

**Highlights:** 9,994 order lines • $2.30M sales • $286.4K profit • 12.47% margin • discount, category, regional, customer and loss-product diagnostics

**Tools:** Excel, Power Query M, Power Pivot, DAX, PivotTables, PivotCharts
