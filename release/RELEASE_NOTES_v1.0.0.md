# Superstore Retail Performance Intelligence v1.0.0

Initial governed portfolio release of the refreshable Excel Business Intelligence solution.

## Included

- Excel workbook with Power Query ETL, Power Pivot relationships, DAX measures and interactive dashboards.
- Professional analytical report.
- Exported Power Query M definitions.
- Complete DAX measure catalogue.
- Data dictionary and refresh runbook.
- Repository visuals and citation metadata.

## Validated baseline

- 9,994 valid sales lines; 0 rejected rows.
- $2,297,200.86 Total Sales.
- $286,397.02 Total Profit.
- 12.47% Profit Margin.
- 5,009 distinct orders and 793 customers.
